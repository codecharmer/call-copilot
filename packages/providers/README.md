# @call-copilot/providers

Adapters that implement the `TranscriptionProvider` and `AnswerProvider` contracts. Initial
candidates: Deepgram streaming (transcription) and the OpenAI Responses API (question
classification and answer generation). Provider and model choice is configuration; model IDs are
pinned at release. See [ADR 0005](../../docs/adr/0005-provider-adapters-are-configuration.md).

Status: placeholder until Phase 2 (transcription) and Phase 1 (answers).
